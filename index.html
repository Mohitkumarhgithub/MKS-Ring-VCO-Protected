01 · Concept

What is a Ring VCO?

A ring voltage-controlled oscillator generates a periodic output by connecting an odd number of inverting delay stages in a closed feedback loop. Changing the control condition changes the propagation delay, which changes the oscillation frequency.

Structure

Odd number of stages

Each CMOS inverter contributes an inversion and a finite propagation delay. Three stages form the feedback loop used in this study.

Control

Delay tuning

Changing NMOS/PMOS sizing or the supply/control voltage changes charging and discharging strength, affecting stage delay and frequency.

Applications

On-chip clock generation

Ring VCOs are useful in PLLs, clock and data recovery, clock generation, frequency synthesis, and timing circuits where compact integration is important.

Common VCO types

VCO classification

LC VCO · Ring VCO · Relaxation VCO · Crystal-based oscillator with voltage tuning.

The ring VCO is the focus of this design.

Why choose a ring VCO?

Key merits

Small silicon area, simple CMOS implementation, easy integration, wide tuning potential, and suitability for multi-phase clock generation. Its main trade-offs are typically higher phase noise and greater supply sensitivity than a well-designed LC VCO.

02 · Building block

First understand the CMOS inverter

A CMOS inverter uses one PMOS transistor as the pull-up device and one NMOS transistor as the pull-down device. Their gates share the input and their drains meet at the output.

Input = LOW

PMOS ON · NMOS OFF

The PMOS connects the output toward VDD. The output becomes logic HIGH.

Vin = 0 → Vout ≈ VDD
Input = HIGH

PMOS OFF · NMOS ON

The NMOS connects the output toward ground. The output becomes logic LOW.

Vin = VDD → Vout ≈ 0

Why the inverter creates delay

The output node has capacitance from transistor junctions, gate loading, wiring, and connected stages. When the input changes, the PMOS or NMOS charges or discharges this capacitance. The finite current and capacitance produce propagation delay (tp). In a ring, each stage passes a delayed, inverted transition to the next stage.

For a practical design, distinguish rise delay (tPLH) and fall delay (tPHL). A common first-order stage delay is td ≈ (tPLH + tPHL)/2.
03 · Three-stage ring

Three inverter stages connected in a loop

This is the functional block representation, not the transistor-level Cadence schematic. The output of the third inverter feeds the input of the first inverter.

▷○
INV-2Inverts + delays
▷○
INV-3Inverts + delays
↶ Feedback: output of INV-3 is connected to input of INV-1

The loop is closed: INV-1 → INV-2 → INV-3 → INV-1. The odd number of inversions makes the loop regenerative with delay, allowing oscillation when the loop gain and phase conditions are satisfied.

04 · Oscillation condition

Rules that must be satisfied

Oscillation is not caused simply by connecting three inverters. The feedback loop must satisfy the phase and gain conditions at the oscillation frequency.

Barkhausen phase condition

Total loop phase

∠Aβ = 0° (mod 360°)

For three inverters, the low-frequency inversion contributes 180° around the loop. The frequency-dependent phase lag from the stages supplies the remaining phase shift so that the total loop phase is 360° (or an integer multiple).

Loop gain condition

Startup and steady state

|Aβ| ≥ 1

For startup, the small-signal loop gain must be greater than unity at the oscillation frequency. As amplitude grows, nonlinear limiting reduces the effective gain toward unity in steady state.

First-order frequency relation

fosc ≈ 1 / (2 N td)   ;   N = 3

For a three-stage ring, fosc ≈ 1/(6td). This is an approximate relation assuming similar stage delays and a simplified transition model. Extract the actual frequency from the Cadence transient waveform rather than relying only on this equation.

Cadence simulation procedure

  1. Open your three-stage ring VCO schematic in Cadence Virtuoso.
  2. Set the NMOS finger-width variable to the recommended NW.
  3. Set the PMOS finger-width variable to the recommended PW.
  4. Set the supply source to the recommended VDD.
  5. Keep the gate length and finger count consistent with your selected 180 nm design setup.
  6. Run transient analysis and wait until the waveform reaches steady-state oscillation.
  7. Measure the output period/frequency and average power, then enter those measured values below.
